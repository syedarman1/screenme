# Security

Please report suspected vulnerabilities privately using [GitHub private vulnerability reporting](https://github.com/syedarman1/screenme/security/advisories/new). If that option is unavailable, use [ScreenMe's contact form](https://www.screenme.dev/contact) and label the topic “Security report.”

Include the affected feature, minimal reproduction steps, expected/actual behavior and the potential impact. Use accounts and data you control. Do not include passwords, API keys, full payment details or another person's resume. Do not publish exploit details in a public issue before coordinated remediation.

The current production release is the supported version. Security fixes are validated through server/API tests and, where relevant, database ownership and billing regression checks. There is no guaranteed response-time SLA or paid bounty program.
